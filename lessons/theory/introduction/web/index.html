一条直线里的
两个参数。

为什么同样是直线，有的上升，有的下降？答案藏在一个很短的式子里。

y = kx + b

01 / 斜率决定变化的方向

当 x 增加 1，y 会增加 k。k 为正，直线向右上方延伸；k 为负，直线向右下方延伸。k 的绝对值越大，在相同坐标比例下，直线越陡。

02 / 截距决定起点的位置

令 x = 0，就得到 y = b。它告诉我们直线与 y 轴相交的位置。保持 k 不变，改变 b，整条直线会平行移动。

03 / 用一个例子连接起来

对于 y = 2x + 1，当 x 分别取 −1、0、1 时，y 分别为 −1、1、3。每次 x 增加 1，y 都增加 2；直线经过点 (0, 1)。
